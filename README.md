# Energy Consumption Prediction Using Machine Learning

## Project Overview
This is a beginner-level Machine Learning project that aims to predict energy consumption using building-related and environmental data.

The project uses Linear Regression to understand the relationship between different features and energy consumption.

## Objectives
- Explore and understand an energy consumption dataset.
- Perform data preprocessing and exploratory data analysis (EDA).
- Apply feature engineering to extract useful information from timestamps.
- Train a Linear Regression model.
- Evaluate the model's performance.

## Dataset
The dataset was obtained from Kaggle and contains information such as:
- Temperature
- Humidity
- Square Footage
- Occupancy
- HVAC Usage
- Lighting Usage
- Renewable Energy
- Day of the Week
- Holiday
- Timestamp

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Methodology
1. Data loading and inspection
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature engineering
5. One-Hot Encoding of categorical features
6. Feature scaling using StandardScaler
7. Training using Linear Regression
8. Model evaluation

## Model Performance
Metric & Result 

R² Score --> 0.6293 
MAE --> 3.9488 
RMSE --> 4.8347 

The model achieved an R² score of approximately 0.6293 on the test dataset.
